# Barbearia Don Mariano – Landing Page

Landing page da Barbearia Don Mariano (Pirituba, São Paulo).

## Estrutura

```
index.html        Página principal
support.js        Runtime da página (obrigatório, mantenha ao lado do index.html)
assets/
  img/            Imagens (.webp)
  video-salao.mp4 Vídeo do hero
  video-barba.mp4 Vídeo da seção "Por que a Don Mariano"
```

## Publicar no GitHub Pages

1. Envie todo o conteúdo desta pasta para a raiz do repositório.
2. Em Settings → Pages, escolha a branch `main` e a pasta `/ (root)`.
3. O site ficará em `https://amdrhub-max.github.io/barbeariadommariano/`.
